ELEVATEWEB BRAND SPECIFICATION

Use the following existing ElevateWeb branding as the source of truth for the visual identity.

Brand identity

Brand: ElevateWeb

The identity should feel:

- Modern
- Technical
- Clean
- Professional
- Confident
- Minimal
- Approachable

Do NOT reinterpret the brand into a generic "AI startup" aesthetic.

The carousel system should feel like it belongs to the same brand as the existing ElevateWeb website and logo, while still being optimized specifically for Instagram.

---

Logo

Use the provided ElevateWeb logo SVG as the authoritative logo asset.

Do not redraw, recreate, distort, rotate, or modify the logo.

The logo mark contains:

- "#2563EB"
- "#1D4ED8"
- "#3B82F6"

The logo contains blue gradient elements between the darker blue tones, while some elements use solid "#3B82F6".

Use the original SVG wherever possible rather than rasterizing it prematurely.

Recommended carousel usage:

- Small, subtle brand mark on most slides
- More prominent logo on the first/last slide when appropriate
- Never allow the logo to compete with the slide headline
- Maintain sufficient clear space around the logo
- Never stretch the logo disproportionately

Color usage rules

Prefer a mostly white/light editorial canvas with strong dark typography and controlled blue accents.

Use:

- Dark text for hierarchy
- Blue for emphasis, labels, key numbers, diagrams and selected UI elements
- Light blue "#EFF6FF" for subtle highlighted areas
- Neutral surfaces for cards/sections
- Thin neutral borders where useful

Avoid:

- Excessive blue backgrounds
- Full-slide saturated blue unless intentionally used for a specific statement/cover slide
- Random additional brand colors
- Purple/pink gradients
- Neon colors
- Glassmorphism
- Excessive shadows
- "AI-generated" visual clichés

The ElevateWeb logo's blue gradient is allowed as part of the logo itself, but do not extend that gradient across the entire design system.

Prefer flat colors for the majority of the carousel.

---

Typography

The existing website uses:

Outfit

Use Outfit as the primary carousel typeface where technically possible.

Typography should have clear hierarchy:

- Large, bold headline
- Medium-weight supporting text
- Smaller metadata/labels
- Strong numerical emphasis where relevant

Prioritize readability at 1080×1350 and on a mobile phone.

Avoid:

- Tiny body text
- Excessive font weights
- Decorative display fonts
- Random font switching
- Generic "startup" typography combinations

The typography should feel geometric, clean and modern.

If the renderer requires a bundled font, use a properly packaged/deployable version of Outfit rather than relying on a font that only exists on the developer's machine.

---

Layout language

The visual language should be:

Editorial + technical + structured

Use:

- Strong alignment
- Generous whitespace
- Clear grid structure
- Asymmetric layouts where appropriate
- Large typography
- Simple geometric elements
- Clean diagrams
- Controlled blue accents
- Strong visual hierarchy

Do not make every slide look like the same template with different text.

Templates should have consistent brand DNA but different compositions.

---

Existing brand vs carousel design

IMPORTANT:

Do not simply copy the ElevateWeb website UI into Instagram slides.

The website and carousel should share:

- Colors
- Typography
- Logo treatment
- General visual personality
- Spacing philosophy
- Overall brand identity

But the carousel needs its own dedicated visual system optimized for:

- 1080×1350
- Mobile viewing
- Fast comprehension
- Large readable typography
- Swipe-based storytelling

The goal is:

Same brand. Different medium.

---

Visual quality bar

A finished carousel should look like it was intentionally designed by a professional designer, not generated by an AI template.

Prioritize:

1. Content hierarchy
2. Typography
3. Spacing
4. Composition
5. Brand consistency
6. Visual explanation
7. Decoration

Never sacrifice readability for decoration.

If a visual element does not improve understanding, hierarchy, or brand recognition, remove it.

---

Source assets

The repository should include/reference the supplied ElevateWeb logo asset.

Do not invent a replacement logo.

If additional brand assets are needed, prefer creating simple reusable geometric components from the existing visual language rather than introducing unrelated illustrations or stock imagery.
